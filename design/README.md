# Design Notes

A living design folder for the magic-academy life sim. These are **notes and
intent**, not specifications — synthesized from ongoing design discussions.
Nothing here dictates code; the prototype under `/scripts`, `/scenes`, `/data`
is a separate, evolving thing that these notes inform over time.

Each doc tags its claims:
- **[DECIDED]** — a working decision (still reversible, but the current lean).
- **[OPEN]** — genuinely undecided; options recorded.
- **[LATER]** — wanted, but out of scope for the first playable base.

## Guiding principle

> "Am I making this for other people or myself?" — make it for yourself.
> **Charm first, legibility second.** The failure mode to avoid is a lifeless
> spreadsheet, even a well-balanced one.
